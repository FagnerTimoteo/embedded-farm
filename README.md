# Granja - Monitoramento com ESP32 (MQTT)

Projeto desenvolvido com **ESP-IDF** para monitoramento e controle utilizando um **ESP32** com comunicação via **MQTT**.

O firmware realiza a leitura de sensores e controla atuadores, enviando os dados para um broker MQTT para integração com sistemas de automação, dashboards ou backends.

---

# 📦 Requisitos

Antes de importar o projeto, instale:

✅ ESP-IDF **(recomendada a mesma versão do projeto)**
✅ Python (instalado automaticamente pelo ESP-IDF)
✅ Ninja + CMake (já inclusos no setup do IDF)
